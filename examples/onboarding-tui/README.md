# Example Onboarding TUI

This crate demonstrates one terminal frontend over `nemoclaw-authoring`.
It is an example, not the prescribed NemoClaw onboarding flow, and it is not included in the native CLI bundle.

The example queries guided fields and compatible choices from the authoring library, submits typed edits, reviews the resulting SDK `Document`, and writes validated desired-state YAML.
It does not read credential values, create deployment state, locate a bundle, plan, or apply resources.

Run it from the repository root in a terminal:

```sh
cargo run -p nemoclaw-onboarding -- --output deployment.yaml
```

Use `--edit FILE` to reopen a document previously generated by this example.
Guided editing rejects documents with additional V1 configuration rather than discarding fields that the example does not expose.

Review the generated YAML before passing it to the independently built `nemoclaw` lifecycle CLI:

```sh
nemoclaw plan deployment.yaml
nemoclaw apply deployment.yaml
```

Those commands are separate actions; accepting the example's review never authorizes a deployment operation.
