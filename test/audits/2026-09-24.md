# Test value audit, 2026-09-24

This audit adds a reusable test-value skill and removes duplicated scenarios and unused test exports.
It preserves distinct inputs, negative controls, cleanup checks, and compatibility contracts.

## Scope and method

The repository-wide discovery pass used tracked files at `6c6b3da7009854f5322074071f44e2bf31dc2209`.
The initial coverage baseline used `2e162f266f583d78392494feff44c360d1390ad0`. The audited behavior owners
and shared Launchable fixture are unchanged between those commits.

| Integration and repository tests | 772 | 290,488 |
| Live E2E | 79 | 36,535 |

| Installer integration | 26 | 16,953 |

| Tool runtime | 1 | 327 |
| Total JavaScript and TypeScript test files | 2,690 | 963,139 |

The audit also inspected two standalone Python test files and three manual shell probe or acceptance
wrappers. Their 189 lines remain unchanged. The five Python tests pass.

Discovery used syntax-aware test-body comparison, similar-body candidates, assertion and helper-call
inspection, imports and consumers, Git history, project routing, and the existing source-shape scanner.
The final exact-body scan found 35 matching groups. Distinct table inputs and different fixture states
accounted for most matches. A broader comparison that ignored literal values produced 232 candidate
groups; embedded scripts and different denial conditions prevent treating those matches as duplicates.

The source-shape scanner reported no unapproved cases and 89 existing reviewed exceptions.
Those security and compatibility exceptions remain. Thirty-four cases without a direct assertion call
were inspected as candidates; throwing helpers, explicit failure callbacks, and nested reporter fixtures
can supply their checks. A repeated serializer call was retained because it checks determinism.

This was a repository-wide discovery audit with manual review of deletion candidates, not a claim that
every test assertion received an independent semantic review. Unproven candidates remain in place.
No live E2E test, assertion budget, coverage threshold, exclusion, or skip was changed.

The audit retains the dashboard compatibility-hook test as the only direct exercise of that entrypoint
in its owner suite. Similar CLI and plugin object-guard tests remain because they cover separate
implementations and compilation boundaries. Rebuild and onboarding journal cases remain because their

Net changes are 710 fewer test lines and 12 fewer production lines. No test-support layer was added.
The existing size limits for `nim.test.ts` and `generate-openclaw-config.test.ts` decrease with the files.
The test-audit skill and contributor routing add 116 guidance lines, counted separately from reductions.

## Validation

- Paired affected-suite runs passed: 743 cases before consolidation and 706 afterward. The retained
  dashboard suite then passed all 16 cases, covering 707 distinct retained cases across the focused runs.
- Ten unchanged source modules have identical covered statement, function, and branch locations in
  the paired reports. The isolated runner comparison also matches all covered locations: 97/129
  statements, 96/138 branches, 15/20 functions, and 91/120 lines. The retained dashboard suite matches
  its baseline coverage. Larger combined runs reported varying runner branch counts, so this audit
  does not claim identical repository-wide coverage.
- The two removed OpenRouter export objects account for two fewer covered initialization statements.
  The adapter's retained branch and function coverage is unchanged.
- The complete non-live macOS run recorded 44,533 passed, 60 failed, and 499 skipped tests across
  2,608 files. None of the changed test files failed. The unchanged dashboard case was retained and
  verified separately after this run. This is not a passing full-suite result.
- Six selected local failures also reproduce on the untouched original baseline: canonical executable
  selection, Portable working-directory reporting, two temporary-path reader checks, and two runtime
  packaging checks requiring GNU tar. Two hard-link cases passed in isolation on the baseline.
  Other full-run failures include timeouts and a Docker bind-mount error; their complete causes were
  not established by this audit. The local environment lacks GNU tar and the broad run used default
  test budgets; the macOS CI workflow configures GNU tools and 60-second test and execution budgets.
- The exact delivery base's [main CI run](https://github.com/NVIDIA/NemoClaw/actions/runs/36026589787)
  passed all 12 CLI shards, plugin tests, and installer integration. Its messaging image construction
  job and aggregate check failed. That image failure is outside this change.
- Test-project membership passed for 2,687 candidates across seven projects. The repository skill
  validator passed all 30 skills, and the standalone Python suite passed five tests.

The PR records publication checks and automated-review results for its current commit.

The broad local baseline was interrupted after failures in unchanged areas; it is not a completed
baseline result. Matching focused runs provide the before/after comparison. The complete candidate
non-live result and the observed baseline failures are recorded separately. Live E2E was not run.
