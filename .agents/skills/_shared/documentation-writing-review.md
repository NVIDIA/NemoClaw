# Documentation Writing and Review Routing

Use this routing contract in any skill that writes or reviews comments, test titles, PR text,
documentation, changelog entries, Announcements, or maintainer guidance.

## Load the Authority for the Surface

- The [NemoClaw Writing Guide](../../../WRITING.md) owns repository-wide explanatory-text rules,
  claim accuracy, examples, review scope, and blocking criteria.
- The [NemoClaw Controlled Word List](controlled-words.md) owns project terms, product names,
  lifecycle operations, and evidence claims.
- The [documentation contributor guide](../../../docs/CONTRIBUTING.md) owns public-facing
  documentation procedures and rules.
- The [Documentation Agent Guide](../../../docs/AGENTS.md) owns agent-specific instructions for
  applying the public-facing documentation rules.
- The repository [Documentation instructions](../../../AGENTS.md#documentation) own agent workflow
  for documentation impact, authoring, independent review, and final handoff.
- The contributor guide's
  [Documentation Writer Review Receipt](../../../CONTRIBUTING.md#documentation-writer-review-receipt)
  and the [PR template](../../../.github/PULL_REQUEST_TEMPLATE.md) own receipt requirements and
  fields.

Read each authority that applies to the changed surface. Do not copy its rule list into a skill.
Use the validation required by the owning workflow.
