# Report a Security Vulnerability

Report a potential NemoClaw vulnerability privately through [NVIDIA's vulnerability-reporting page](https://www.nvidia.com/en-us/security/report-vulnerability/).
It links the disclosure program and lists NVIDIA PSIRT at `psirt@nvidia.com`.
For email, encrypt the report using the [current NVIDIA PGP key](https://www.nvidia.com/en-us/security/pgp-key/).
Do not put vulnerability details in public issues or pull requests.

Include the affected branch and source/bundle revision, reproduction steps, potential impact, and a minimal proof of concept when available.
Remove unrelated credentials, private conversations, and deployment data from attachments.
The [security guide](docs/security.md) describes v1's implementation boundaries; passing tests do not establish security qualification for every host or configuration.
