NemoClaw Agent Configs is installed

Open a new Terminal window, then check the CLI with nemoclaw --version. Terminal windows that were open during the installation do not have it on PATH.

Before your first deployment

NemoClaw runs agents in a container engine. Install and start one of these:

  • Docker Desktop
  • Podman, with a Podman machine

Next steps

  1. In a directory for your deployment, run nemoclaw onboard. It asks for your choices and writes deployment.yaml.
  2. Follow the first-deployment guide.

To upgrade or uninstall, refer to Installing the CLI.
