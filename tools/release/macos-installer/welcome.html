NemoClaw Agent Configs {{VERSION}}

This installer puts the nemoclaw CLI, with the OpenTofu, providers, and schemas it uses, in {{INSTALL_DIR}}. It also adds {{INSTALL_DIR}}/bin to PATH for new Terminal windows.

It requires a Mac with Apple silicon and macOS {{MINIMUM_MACOS}} or later.

Upgrading

Installing replaces the version in {{INSTALL_DIR}}. A deployment keeps using the release that created it, so before you upgrade, destroy the deployments that the installed version created, or keep that release's archive to destroy them later.

Deployment YAML and state directories stay where you created them.
