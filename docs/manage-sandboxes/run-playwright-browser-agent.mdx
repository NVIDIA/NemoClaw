Run Playwright and Chromium inside a NemoClaw-managed OpenClaw sandbox.
The browser remains subject to the sandbox filesystem and deny-default network policies.

<Warning>
This source-based workflow targets NemoClaw `v0.0.80`.
Your installed CLI, source checkout, and `sandbox-base` image must use the same release because `nemoclaw onboard --from` treats the supplied Dockerfile as the complete sandbox image.
</Warning>

## Compare Browser Options

Hermes sandboxes can use the managed `browser-use` tool through the `nous-browser` policy preset.
That option runs a browser in the Browser Use cloud service.
This page covers an OpenClaw sandbox that runs Chromium locally.

| | Managed `browser-use` | Self-hosted Playwright |
|---|---|---|
| Browser location | Browser Use cloud | OpenClaw sandbox |
| Setup | Managed tool and policy preset | Version-matched custom image and policy |
| Browser service dependency | Nous Portal and `*.browser-use.com` | No managed browser service |
| Target dependencies | Managed by the service | Every page, CDN, font, analytics, and OAuth host must be allowed |

Use the self-hosted path when you need local browser execution or direct control over the browser image and egress policy.

## Understand the Security Boundaries

The browser must satisfy three independent boundaries.

<AccordionGroup>
  <Accordion title="Egress Policy">

Sandbox egress is deny-default.
The policy must include the target site and every host that the page loads, including CDNs, fonts, analytics, and OAuth endpoints.

For Google Forms, commonly required hosts include `docs.google.com`, `www.google.com`, `*.gstatic.com`, `*.googleapis.com`, and `accounts.google.com`.
Inspect policy denials and add only the hosts and HTTP methods that the target requires.

  </Accordion>
  <Accordion title="SSRF Protection">

OpenShell evaluates every resolved destination, including redirect targets, against its SSRF protections.
Allowing the first download host does not authorize a later redirect to a blocked address.

Do not widen SSRF ranges to make a runtime browser download work.
Install Playwright's matched browser during the image build, before the sandbox policy applies.

  </Accordion>
  <Accordion title="Filesystem Policy">

Landlock grants access by filesystem path, not by when a file was created.
The stock OpenClaw policy grants read access under `/usr` and does not grant `/root`.

Install the browser under `/usr/local/lib/ms-playwright` so the runtime can execute a root-owned, image-baked browser from an allowed read-only path.
Do not rely on Playwright's default cache under a user home directory.

  </Accordion>
</AccordionGroup>

## Build the Browser Image

The custom image must preserve NemoClaw's complete managed runtime.
Start from a version-matched source checkout and append one final browser layer to the stock Dockerfile.

<Steps>
  <Step title="Prepare the source context">
    Confirm your CLI version and check out the matching release.

    ```bash
    nemoclaw --version
    git clone --depth 1 --branch v0.0.80 \
      https://github.com/NVIDIA/NemoClaw.git playwright-sandbox
    cd playwright-sandbox
    ```

    Use the release reported by `nemoclaw --version` when it is not `v0.0.80`.
  </Step>

  <Step title="Name the completed managed stage">
    Change the stock Dockerfile's final base line so the completed runtime can be extended.

    ```diff
    -FROM ${BASE_IMAGE}
    +FROM ${BASE_IMAGE} AS nemoclaw-runtime
    ```
  </Step>

  <Step title="Append the Playwright stage">
    Append this stage to the end of the stock Dockerfile.

    ```dockerfile
    FROM nemoclaw-runtime AS playwright-runtime

    ARG NEMOCLAW_TOOL_DISCLOSURE=progressive
    ARG PLAYWRIGHT_VERSION=1.61.0
    ENV NEMOCLAW_TOOL_DISCLOSURE=${NEMOCLAW_TOOL_DISCLOSURE} \
        PLAYWRIGHT_BROWSERS_PATH=/usr/local/lib/ms-playwright

    USER root
    RUN pip3 install --no-cache-dir --break-system-packages \
          "playwright==${PLAYWRIGHT_VERSION}" \
        && python3 -m playwright install --with-deps chromium \
        && apt-get update \
        && apt-get install -y --no-install-recommends libnss3-tools \
        && rm -rf /var/lib/apt/lists/* \
        && chmod -R a+rX "${PLAYWRIGHT_BROWSERS_PATH}"

    USER sandbox
    WORKDIR /sandbox
    ```

    The pinned Playwright package installs its matching Chromium and FFmpeg revisions under `PLAYWRIGHT_BROWSERS_PATH`.
    The `libnss3-tools` package supplies `certutil`, which the script below uses to trust the OpenShell proxy CA without disabling certificate validation.
  </Step>

  <Step title="Onboard from the custom Dockerfile">
    Pin the base image to the same NemoClaw release and create a registered custom-image sandbox.

    ```bash
    NEMOCLAW_SANDBOX_BASE_IMAGE_REF=ghcr.io/nvidia/nemoclaw/sandbox-base:v0.0.80 \
      nemoclaw onboard \
        --fresh \
        --no-gpu \
        --name playwright-agent \
        --from "$PWD/Dockerfile"
    ```

    Keep the source checkout at this path because `nemoclaw playwright-agent rebuild` uses the recorded Dockerfile again.
  </Step>
</Steps>

## Apply the Browser Policy

Save the following custom preset as `egress-policy.yaml`.
Replace `example.com` with the target host and add a separate endpoint for each page dependency.

```yaml
preset:
  name: playwright-browser-agent
  description: "Egress policy for a self-hosted Playwright browser."

network_policies:
  playwright-browser-agent:
    name: playwright-browser-agent
    endpoints:
      - host: example.com
        port: 443
        protocol: rest
        enforcement: enforce
        rules:
          - allow: { method: GET, path: "/**" }
          - allow: { method: HEAD, path: "/**" }
          - allow: { method: OPTIONS, path: "/**" }
          - allow: { method: POST, path: "/**" }
    binaries:
      - { path: /usr/local/lib/ms-playwright/** }
```

Preview and apply the preset.

```bash
nemoclaw playwright-agent policy-add --from-file egress-policy.yaml --dry-run
nemoclaw playwright-agent policy-add --from-file egress-policy.yaml
```

NemoClaw records custom presets in the sandbox registry and reapplies them during managed rebuilds.
Review each added host because a custom preset expands the browser's egress boundary.

## Drive the Browser

The example below preserves TLS verification by importing the OpenShell proxy CA into Chromium's NSS database.
It uses the browser revision installed by the pinned Playwright package and explicitly keeps headless mode enabled for the sandbox.

Replace the URL, field values, submit control name, and unique success text for your target page.

```python
import os
import subprocess
from pathlib import Path

from playwright.sync_api import TimeoutError as PlaywrightTimeoutError
from playwright.sync_api import sync_playwright

FORM_URL = "https://example.com/your-form"
FIELD_VALUES = ["First field value", "Second field value"]
SUBMIT_TEXT = "Submit"
SUCCESS_TEXT = "Thank you"
VIDEO_DIR: str | None = None
FIELD_SELECTOR = (
    'input[type="text"]:not([readonly]):not([disabled]), '
    "textarea:not([readonly]):not([disabled])"
)


def trust_openshell_proxy_ca() -> None:
    """Import the OpenShell proxy CA into Chromium's per-user NSS database."""
    ca_bundle = os.environ.get("SSL_CERT_FILE")
    if not ca_bundle or not Path(ca_bundle).is_file():
        raise RuntimeError(
            "SSL_CERT_FILE is unavailable; source /tmp/nemoclaw-proxy-env.sh "
            "before running the script"
        )

    legacy_nss_dir = Path.home() / ".pki" / "nssdb"
    nss_dir = (
        legacy_nss_dir
        if legacy_nss_dir.is_dir()
        else Path.home() / ".local" / "share" / "pki" / "nssdb"
    )
    nss_dir.mkdir(parents=True, exist_ok=True)
    database = f"sql:{nss_dir}"
    if not (nss_dir / "cert9.db").exists():
        subprocess.run(
            ["certutil", "-d", database, "-N", "--empty-password"],
            check=True,
        )

    nickname = "OpenShell egress proxy CA"
    subprocess.run(
        ["certutil", "-d", database, "-D", "-n", nickname],
        stdout=subprocess.DEVNULL,
        stderr=subprocess.DEVNULL,
        check=False,
    )
    subprocess.run(
        [
            "certutil",
            "-d",
            database,
            "-A",
            "-t",
            "C,,",
            "-n",
            nickname,
            "-i",
            ca_bundle,
        ],
        check=True,
    )


def fill_form(
    url: str,
    values: list[str],
    submit_text: str,
    success_text: str,
    video_dir: str | None = None,
) -> str:
    """Fill every visible text field, submit, and return the final title."""
    trust_openshell_proxy_ca()

    with sync_playwright() as playwright:
        browser = playwright.chromium.launch(headless=True)
        context = None
        try:
            context = browser.new_context(record_video_dir=video_dir)
            page = context.new_page()
            page.goto(url, wait_until="domcontentloaded")

            fields = page.locator(FIELD_SELECTOR).filter(visible=True)
            try:
                page.wait_for_function(
                    """
                    selector => {
                      const fields = [...document.querySelectorAll(selector)]
                        .filter(field => {
                          const style = window.getComputedStyle(field);
                          return style.display !== "none"
                            && style.visibility !== "hidden"
                            && field.getClientRects().length > 0
                            && !field.disabled
                            && !field.readOnly;
                        });
                      return fields.length > 0;
                    }
                    """,
                    arg=FIELD_SELECTOR,
                    timeout=15000,
                )
            except PlaywrightTimeoutError as error:
                raise RuntimeError(
                    "No visible editable fields appeared; check the page selectors "
                    "and denied dependency hosts"
                ) from error

            field_count = fields.count()
            if field_count != len(values):
                raise ValueError(
                    f"Expected {len(values)} visible fields, found {field_count}"
                )

            for index, value in enumerate(values):
                field = fields.nth(index)
                field.fill(value)
                print(f"field {index + 1}: filled ({len(value)} chars)")

            page.get_by_role("button", name=submit_text, exact=True).click()
            page.get_by_text(success_text, exact=False).filter(visible=True).first.wait_for(
                state="visible",
                timeout=15000,
            )
            return page.title()
        finally:
            try:
                if context is not None:
                    context.close()
            finally:
                browser.close()


if __name__ == "__main__":
    print(
        fill_form(
            FORM_URL,
            FIELD_VALUES,
            SUBMIT_TEXT,
            SUCCESS_TEXT,
            VIDEO_DIR,
        )
    )
```

Upload and run the script through the supported NemoClaw commands.
Source the managed proxy environment so the browser receives the proxy settings and `SSL_CERT_FILE` path.

```bash
nemoclaw playwright-agent upload \
  ./fill_form_example.py /sandbox/fill_form_example.py
nemoclaw playwright-agent exec -- bash -lc \
  '. /tmp/nemoclaw-proxy-env.sh && python3 /sandbox/fill_form_example.py'
```

For production automation, prefer role, label, or test-ID locators that match the target site's stable user-facing contract.
The generic field selector is a starting point for simple forms.

## Record Video

Set `VIDEO_DIR` in the Python example to a writable sandbox path such as `/sandbox/playwright-videos`.
The matched Playwright install already includes its compatible FFmpeg binary under `/usr/local/lib/ms-playwright`.
Playwright writes each video when its browser context closes, as described in the [Playwright video guide](https://playwright.dev/python/docs/videos).

The `finally` block closes the browser context before the function returns, which flushes the video files.
Download videos only after the script exits.

```bash
nemoclaw playwright-agent download \
  /sandbox/playwright-videos ./playwright-videos
```

<Warning>
Browser videos can contain form data, credentials, and personal information.
Protect or delete them according to your data-handling requirements.
</Warning>

## Troubleshoot the Workflow

| Symptom | Cause | Fix |
|---|---|---|
| Proxy `403` or `policy_denied` | A page dependency or browser binary does not match the policy | Add the exact host and required method, and keep `/usr/local/lib/ms-playwright/**` in `binaries` |
| `ssrf_denied` during a browser download | A runtime download or redirect reached a blocked destination | Keep the browser install in the Dockerfile and rebuild the image |
| `net::ERR_CERT_AUTHORITY_INVALID` | Chromium did not receive the OpenShell proxy CA | Source `/tmp/nemoclaw-proxy-env.sh` and confirm `SSL_CERT_FILE` points to a readable file |
| No visible enabled fields | The selector is wrong or a required script host is denied | Inspect the page and OpenShell policy denials, then update the selector or policy |
| Field count mismatch | The configured values do not match the visible target fields | Use site-specific locators or update `FIELD_VALUES` |
| Success wait times out | The submit failed or `SUCCESS_TEXT` is not unique to the completed state | Inspect the response and use a reliable success locator or URL contract |
| Videos are missing | The context did not close or `VIDEO_DIR` is unset | Set a writable path and let the script exit normally before downloading files |
