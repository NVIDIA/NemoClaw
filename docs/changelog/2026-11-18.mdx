## v0.0.145

NemoClaw v0.0.145 improves onboarding recovery, Deep Agents state restoration, and Hermes routing verification.

### Onboarding and Recovery

- NVIDIA Endpoints onboarding retains the selected provider and model on resume.
  Explicit selections override saved selections, and verified resume recovery can reuse recorded native-provider credentials when the host environment lacks the inference key.
  Related changes: [PR #14438](https://github.com/NVIDIA/NemoClaw/pull/14438) and [PR #14389](https://github.com/NVIDIA/NemoClaw/pull/14389).
- Docker readiness timeouts report the validated selected endpoint when available without claiming that the daemon stopped.
  Related change: [PR #14438](https://github.com/NVIDIA/NemoClaw/pull/14438).
- For managed Deep Agents images, recreation for a verified provider or model change keeps the replacement's generated configuration and retains the previous file in the backup.
  Unchanged or unverifiable selections and custom images retain native configuration restoration.
  Related change: [PR #13954](https://github.com/NVIDIA/NemoClaw/pull/13954).
- Deep Agents backups distinguish credential-shaped content from inspection, extraction, and deadline failures without printing matched text.
  Quoted SQL examples with unquoted `?` bind parameters no longer cause a credential refusal by themselves.
  Related changes: [PR #14494](https://github.com/NVIDIA/NemoClaw/pull/14494) and [PR #14358](https://github.com/NVIDIA/NemoClaw/pull/14358).
- Onboarding refusals for unowned providers preserve the complete shell-quoted removal command.
  Whitespace-only tool-disclosure environment values use the unset behavior.
  Related changes: [PR #14157](https://github.com/NVIDIA/NemoClaw/pull/14157) and [PR #14509](https://github.com/NVIDIA/NemoClaw/pull/14509).
- Sandboxes whose Microsoft Teams channel was added before OpenClaw 2026.10.5 load again after an upgrade.
  The registry converts that older Teams webhook setting when it reads the saved workload receipt, so `nemoclaw list`, `status`, and the pre-upgrade backup no longer fail on it.
  Malformed or edited profiles are still rejected.
  Related change: [PR #14545](https://github.com/NVIDIA/NemoClaw/pull/14545).

### Hermes Routing and Startup

- Hermes routing verification requires fresh host preflight evidence for provider bindings, effective policy, protected configuration, and gateway process identity.
  Missing or changed evidence blocks verification without changing provider state.
  A direct capable-provider request is reported separately and does not establish adaptive routing.
  Related change: [PR #14560](https://github.com/NVIDIA/NemoClaw/pull/14560).
- Generated Switchyard clients use a 120-second deadline per physical provider call, no automatic retries, and no caller credential forwarding.
  These settings do not define a whole-turn deadline or response-size limit.
- Hermes startup can remove qualified sandbox-owned generated policy sources when root cleanup is refused, while retaining protected policy installation.
  Related change: [PR #14496](https://github.com/NVIDIA/NemoClaw/pull/14496).
- Hermes dashboard documentation specifies both environment settings required for the optional in-browser TUI tab.
  Related change: [PR #14374](https://github.com/NVIDIA/NemoClaw/pull/14374).

### OpenClaw, Downloads, and Installer Safety

- OpenClaw preserves tools for bounded long ordinary and local prompts when web search is disabled, while retaining web-research gating.
  Related change: [PR #14466](https://github.com/NVIDIA/NemoClaw/pull/14466).
- Directory downloads preserve long member filenames that fit the host filesystem limit.
  Related change: [PR #14120](https://github.com/NVIDIA/NemoClaw/pull/14120).
- Installer metadata reads treat checkout paths as data, including quotes and shell metacharacters.
  Security-review tooling uses the verified PR base and literal paths and includes changed submodule commits without running configured diff helpers.
  Related change: [PR #14562](https://github.com/NVIDIA/NemoClaw/pull/14562).

### Validation and Documentation

- Upgrade qualification adds recent-release scenarios and reduces duplicate stopped-sandbox coverage.
  Native Hermes Switchyard tests cover routing boundaries.
  Reviewed OpenShell upgrades prepare trusted audit inputs, and reusable image publication can run its required audit.
  Related changes: [PR #14335](https://github.com/NVIDIA/NemoClaw/pull/14335), [PR #14462](https://github.com/NVIDIA/NemoClaw/pull/14462), [PR #14512](https://github.com/NVIDIA/NemoClaw/pull/14512), [PR #14499](https://github.com/NVIDIA/NemoClaw/pull/14499), and [PR #14555](https://github.com/NVIDIA/NemoClaw/pull/14555).
- Sandbox documentation clarifies readiness and recovery guidance.
  Related change: [PR #14570](https://github.com/NVIDIA/NemoClaw/pull/14570).
