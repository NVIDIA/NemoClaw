## v0.1.0

NemoClaw v0.1.0 introduces YAML configurations for deploying sandboxed agents.
Use the NemoClaw CLI to preview and apply changes, export the observed configuration, or remove managed workloads.

- Follow [Deploying Your First OpenClaw Agent](../get-started/first-deployment.md) to create a deployment.
- To try v1 with settings from a v0 deployment, [convert its configuration export](../get-started/migration.md#starting-from-the-earlier-export) and use a separate state directory.
- Refer to [Current Limits](../resources/limits.md) for known issues with installation, model services, and deployment state.
