## v0.0.137

NemoClaw v0.0.137 changes the default hosted model for new NVIDIA Endpoints and OpenRouter onboarding to Nemotron 3.5 Super VL.
It also repairs policy recovery, agent input, and startup behavior across supported agents.

- New NVIDIA Endpoints onboarding defaults to `nvidia/nemotron-3.5-super-vl-120b-a12b`.
  OpenRouter uses its catalog ID, `nvidia/nemotron-3.5-super-vl`.
  Explicit model selections and the Deep Agents Code Ultra default remain unchanged.
  Related change: [PR #13542](https://github.com/NVIDIA/NemoClaw/pull/13542).
- Onboarding preserves OpenRouter pricing-route IP pins when it applies the built-in pricing policy.
  If OpenShell refuses a policy write, `onboard --resume` reuses the saved preset selection for the same sandbox and confirms the live policy before clearing it.
  An unavailable saved preset stops recovery with a `--fresh` hint.
  Related change: [PR #13499](https://github.com/NVIDIA/NemoClaw/pull/13499).
- `nemoclaw <sandbox> agent` accepts piped messages without an inline `--message` and applies the input deadline to stalled pipes.
  Deep Agents Code readiness and its Auto classifier now use the selected managed Ultra route and required request parameters.
  Related change: [PR #13444](https://github.com/NVIDIA/NemoClaw/pull/13444).
- Pi restores its previous model catalog if settings synchronization fails and updates settings atomically.
  It preserves configured catalog and settings symbolic links, including links to targets that do not yet exist.
  Related change: [PR #13370](https://github.com/NVIDIA/NemoClaw/pull/13370).
- New skill installations reject names longer than 64 characters with a specific validation error.
  Removal still accepts previously installed longer names.
  Related change: [PR #13488](https://github.com/NVIDIA/NemoClaw/pull/13488).
- Portable Hermes onboarding and `doctor` use the same native gateway readiness and receipt authority checks.
  On authority mismatch, both stop with preservation guidance instead of attempting generic recovery.
  Related change: [PR #12244](https://github.com/NVIDIA/NemoClaw/pull/12244).
