# Release Notes

## v0.1.0 (Unreleased)

NemoClaw 0.1.0 is the first planned release on the v1 track. The available tags are release candidates. [Issue #12638](https://github.com/NVIDIA/NemoClaw/issues/12638) tracks the first release.

- Define a deployment in YAML and use the CLI to plan, apply, export, or destroy it. Refer to [Deploying Your First OpenClaw Agent](../get-started/first-deployment.md).
- Review changes since each candidate, [breaking changes and migration steps](../about/release-notes.md#breaking-changes-and-migration), and the [support matrix](../about/release-notes.md#support-matrix) in the [development notes](../about/release-notes.md).
- Check [Current Limits](../resources/limits.md) for known issues before deploying.
