NemoClaw publishes clean Markdown versions of its Fern documentation for AI coding assistants.
Your assistant can fetch the same canonical pages that appear on the docs site, then apply that guidance to your local setup.

Use this page when you want your assistant to help with installation, inference configuration, network policy management, monitoring, deployment, security, workspace management, or command reference lookup.

<Note>
NemoClaw no longer generates a separate user skill for every documentation section.
The documentation is the source of truth, and AI agents should fetch the Markdown docs directly.
</Note>

## Give Your Assistant the Starter Prompt

The fastest path is to copy the starter prompt from the NemoClaw home page and paste it into your local coding assistant.
The prompt tells the assistant to use the Markdown docs, ask one question at a time, run commands only with permission, and handle credentials safely.

Open the [NemoClaw home page](../home) and click **Copy Starter Prompt**.

## Markdown Documentation Entry Points

Give your assistant these URLs when it needs source material:

- Documentation index for AI clients: `https://docs.nvidia.com/nemoclaw/llms.txt`.
- OpenClaw home: `https://docs.nvidia.com/nemoclaw/latest/user-guide/openclaw/home.md`.
- OpenClaw prerequisites: `https://docs.nvidia.com/nemoclaw/latest/user-guide/openclaw/get-started/prerequisites.md`.
- OpenClaw quickstart: `https://docs.nvidia.com/nemoclaw/latest/user-guide/openclaw/get-started/quickstart.md`.
- Hermes home: `https://docs.nvidia.com/nemoclaw/latest/user-guide/hermes/home.md`.
- Hermes prerequisites: `https://docs.nvidia.com/nemoclaw/latest/user-guide/hermes/get-started/prerequisites.md`.
- Hermes quickstart: `https://docs.nvidia.com/nemoclaw/latest/user-guide/hermes/get-started/quickstart.md`.

If your assistant finds a rendered HTML documentation page, tell it to use the same URL with `.md` appended or replacing `.html`.

## Optional Docs-Routing Skill

If your coding assistant supports local project skills, you can fetch the single user skill that encodes the same routing rules.
This skill is small because it points back to the Markdown docs instead of copying the docs into the repository.

Fetch only the docs-routing skill and root instructions without downloading the full source tree:

```bash
git clone --filter=blob:none --no-checkout https://github.com/NVIDIA/NemoClaw.git
cd NemoClaw
git sparse-checkout set --no-cone '/.agents/skills/nemoclaw-user-guide/**' '/.claude/**' '/AGENTS.md' '/CLAUDE.md'
git checkout
```

Open the `NemoClaw` directory in your AI coding assistant.
The assistant discovers `nemoclaw-user-guide` and uses it to fetch the relevant Markdown documentation.

## What to Ask

Ask your assistant a NemoClaw question in natural language.
For example:

- "Help me install NemoClaw with OpenClaw on macOS."
- "Use the NemoClaw Markdown docs and switch my sandbox to Ollama."
- "A network request was blocked. Help me approve it safely."
- "Show me how to inspect sandbox logs and troubleshoot startup."
- "Use the Hermes docs variant and help me add a messaging channel."
