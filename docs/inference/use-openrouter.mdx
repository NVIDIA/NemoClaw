OpenRouter provides an OpenAI-compatible Chat Completions route for OpenClaw, Hermes, and LangChain Deep Agents Code.
The sandbox calls `https://openrouter.ai/api/v1` through its attached OpenShell provider.

## Credential

Set `OPENROUTER_API_KEY` in the host shell before onboarding.
Valid OpenRouter keys begin with `sk-or-`.
NemoClaw validates that the key is non-empty and uses the expected prefix.

## Model Choices

OpenRouter uses the same catalog-backed picker flow and source catalog as NVIDIA Endpoints. It does not apply NVIDIA Endpoints retirement filters and uses its own bundled fallback list, so the available choices can differ.
You can also enter any OpenRouter model ID manually.
NemoClaw validates manual entries with OpenRouter before continuing.

## Onboard

Run the onboarding wizard and select **OpenRouter**.

```bash
$$nemoclaw onboard
```

NemoClaw installs its OpenRouter provider profile and attaches the provider to the selected sandbox.

## Request Headers

NemoClaw configures the agent to send the `HTTP-Referer` and `X-OpenRouter-Title` attribution headers.
OpenShell keeps the API key outside the sandbox and replaces the agent's credential placeholder for approved OpenRouter requests.

## Validation

Host-side catalog, model, and smoke validation use `/v1/chat/completions` only.
NemoClaw skips the Responses API probe and uses managed Chat Completions at runtime.
