NemoClaw no longer installs or starts the built-in Model Router because its `llm-router` dependency is deprecated.
The `routed` and `nvidia-router` selections are unavailable, including when resuming an old onboarding session.
NemoClaw rejects those selections without migrating providers or cleaning up existing resources.

[Choose a supported inference provider](../learn-and-choose/choose-inference-provider) for a new onboarding attempt.
If a previous run retained router recovery metadata, inspect and clean up those resources before starting a new onboarding session.
Use a new sandbox name to preserve an existing sandbox while configuring its replacement.
Removal of the built-in router does not create an automatic migration to NeMo Switchyard.

## Remove an Existing Installation

Back up any sandbox data you want to keep before destroying a sandbox or uninstalling NemoClaw.
Destroy removes the selected sandbox and its workspace.
A new onboarding attempt does not copy the old workspace or provider configuration.

Use the existing [sandbox destroy or uninstall commands](../../manage-sandboxes/operate-sandboxes/uninstall-nemoclaw) to remove retained resources explicitly.
Legacy router metadata and provider attachment records remain readable for ownership checks during cleanup.
NemoClaw does not stop arbitrary processes or remove credentials when it rejects a retired selection.

## Router and Sandbox Lifecycle Locks

The sandbox `destroy` command retains the router-port and sandbox lifecycle locks.
Before stopping a recorded router, `destroy` checks process ownership and other sandbox references.
If ownership or remaining references cannot be established, `destroy` preserves the router and its recovery metadata for inspection.
Use the [destroy command reference](../../reference/commands#$$nemoclaw-name-destroy) for recovery guidance.
Uninstall has a broader removal scope; follow the [uninstall instructions](../../manage-sandboxes/operate-sandboxes/uninstall-nemoclaw) before using it.
Do not kill a process using only a stale recorded PID.
