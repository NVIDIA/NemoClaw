# Internal Security Review Evidence

This directory preserves point-in-time dependency, migration, and security review evidence that tests or maintainers still use.
It is not part of the public documentation set.

Keep user-facing security behavior and procedures in `docs/security/`.
Keep review findings, concern ledgers, release qualification records, and other maintainer evidence here, in the owning component, or in the pull request that performed the review.
Do not add Fern dependency review records here. Keep Fern upgrade evidence in the pull request and executable configuration and publishing tests.
Do not add these artifacts to `docs/index.yml` or link to them from public documentation.
